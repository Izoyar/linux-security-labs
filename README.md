# OverTheWire: Bandit Walkthroughs

This repository contains my personal documentation and step-by-step walkthroughs for the **OverTheWire Bandit** wargame. 

## About the Project
Bandit is a command-line security challenge designed to build practical Linux, networking, and file-system navigation skills. Each level requires using native Linux utilities to locate hidden files, inspect permissions, parse text, and securely connect to remote servers.

## Skills Practiced
* **Remote Access:** Connecting to remote Linux environments via SSH.
* **File System Navigation:** Inspecting hidden files, special characters, and directory structures (`ls`, `cd`, `find`, `file`).
* **Data Filtering & Parsing:** Searching and decoding file contents (`cat`, `grep`, `sort`, `uniq`, `strings`, `base64`).
* **Permissions & Networking:** Analyzing file permissions, network ports, and basic cryptography concepts.
